# Map code audit, 2026-11-08

Audit of the 2D and 3D map code at `b423d305`, challenged by a second reviewer,
fixed on `main`, then reviewed again. Finding IDs match the commit history.

| Finding | Fix | Evidence |

## Changed but not fully proven

- **A2 resize moveend:** the option is asserted, but the native peak-feed rate
  during a drag was not measured on the live site.
- **A5 hidden-tab deadlines:** the helper is unit tested; no real backgrounded
  load was run. A map scrolled offscreen during boot is still unprotected.
- **A6 wildfire retention:** session behavior is tested. The popup reopen in real
  Leaflet and MapLibre has no test.
- **A7 toggle coalescing:** existing tests pass, with no burst-count test or live
  marker measurement.
- **A8 repaint reduction:** behavior is covered, not the amount of work saved.
- **A12 scrubber:** only the newest position reaches the worker, but the dot still
  hides while an update is pending, so it can stay hidden during a very fast scrub.
- **Analyzer view switch restarting 3D:** covered at the bridge, not end to end.
- **Native focus and window placement:** every browser run was hidden.

## Intentionally not changed

- **A14 raw overlay tile bytes:** rejected. Decoding must stay for validation, so
  it saves only a PNG encode and adds a second code path. Revisit with a profile.
- **Scrubber hide-while-pending:** the stale-dot rule is deliberate. Dropping it is
  an owner decision.
- **Panning while 3D boots:** 3D still opens at the camera from the click.
- **Enabling 3D from another tab while consent is pending:** reports a timeout
  rather than starting, because the original click's token has lapsed.
