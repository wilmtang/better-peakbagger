How to fix URL / CORS errors

Check the URL, format and zoom range. Public sources need browser access (CORS), usually Access-Control-Allow-Origin: *. Private parameters use BPB’s limited background relay after provider permission and map approval. A working image link alone does not prove canvas/WebGL access.
