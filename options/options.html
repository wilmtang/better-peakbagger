General

Feature switch

Automatically detect Garmin activitiesFind new activities and prepare ascent drafts. Requires your own Garmin API key in Garmin connection.
Sun & Moon Show the Sun & Moon section on peak pages and ascent GPX charts.
Weather forecast and archive Show summit weather on peak pages and the weather archive on ascent pages. Weather powered by Open-Meteo. Free weather access is subject to fair-use limits.
Summit Cloud Cover Experimental Estimate cloud at summit height and nearby view obstruction. Choose and remember a forecast model on the card. Accuracy is not yet validated.
SNOTEL snow observations Show nearby NRCS snow readings and SNOTEL stations on peak maps in the western US and Alaska.
Enable experimental 3D map Experimental Shows a 3D terrain option on ascent maps, Full Screen GPS maps, and Peak pages. Loading it requests elevation tiles from open-source project Mapterhorn; choosing OSM Vector requests map tiles from OpenFreeMap. Those services receive the viewed map area and request metadata.

Capture & reports

GPX capture

Retain GPX waypoints Include waypoint names and coordinates in the GPX sent to Peakbagger. Other waypoint details remain excluded.
Ascent details Fill elevation, distance, time, and gain for the route up and down, plus statistics for each day shown.
Trip info for multiple peaks Create one Peakbagger trip named for the activity’s start date, or the selected summits when no date is available. Sequence peaks in track order.
Wilderness nights for overnight ascents Set nights from the GPX date span and show the day-by-day table for overnight ascents.
External trip report link Put the captured Garmin or Strava link into Peakbagger’s “URL Link to External Trip Report” field when it is empty.
Remove GPX timestamps Remove recorded times from GPX uploaded to Peakbagger, including captures and files you attach. You can include them for one capture or file. Ascent dates and calculated durations still fill normally.

Report editor

Report editor Replace the ascent form’s trip report box with a rich text and Markdown editor that saves in Peakbagger’s own format, with drafts kept on this device. “Plain” mode inside the editor is the original textarea.
Support development by crediting Better Peakbagger Add a small, editable store link to blank trip reports. You can change or remove it before saving.

Report photos

ImgBB API key The photo topo editor uploads your image to ImgBB, a free image hosting site, and puts the public link in your trip report. Sign in there, choose Get API key, and paste the key here. Uploads are yours and follow ImgBB’s terms of service. The saved key remains in device-local extension storage. Read the photo guide for more info.

          Photo library backup

          GitHub photo backup Checking connection… Stores what your photo library knows: annotations, titles and descriptions, public ImgBB links, image hashes, and which reports used each photo — as photo-library.json. It does not store the images themselves, your ImgBB API key, or the links that delete a photo from ImgBB, so a restore brings back the record, not the picture.
